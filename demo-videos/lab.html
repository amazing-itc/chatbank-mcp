ChatBank MCP Kit

Como usar

Laboratório do banco demo. Mesmos payloads do Inspector.

Conectar o host MCP

O kit sobe em http://localhost:8080/mcp (Streamable HTTP). No Inspector, esse é o único endereço. 

Servidor chatbank-mcp 0.1.0
Tools: consultar_saldo · consultar_extrato · render_saldo · render_extrato
Somente leitura. Sem senha ou OTP.

consultar_saldo

Peça o saldo de uma conta estável. Valores vêm em centavos (152345 = R$ 1.523,45).

consultar_extrato

Use conta-pf-carla para paginação. O tipo PIX no filtro é só categoria de lançamento — o kit não envia PIX.

Conta inexistente

O adapter lança ContaNaoEncontradaException. A tool devolve isError, sem stack.

Plugar o seu banco

Um único ponto de troca: implemente BankingProvider e registre o bean. O mock some sozinho.

@Bean
BankingProvider meuBanco(MeuClient client) {
    return new MeuBancoProvider(client);
}
